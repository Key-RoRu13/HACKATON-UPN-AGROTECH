# Dataset de palta

Coloca aquí el ZIP original o su contenido descomprimido, conservando nombres y etiquetas. No hace falta reorganizarlo antes de revisarlo.

Los archivos del dataset no se publican ni se incorporan automáticamente a la aplicación. Ya existen modelos locales experimentales conectados: condiciones visibles y madurez Hass de cinco etapas. Consulta `ml/RESULTADO_HASS.md` para las métricas internas y sus límites.

Para empezar pruebas con fotos propias, utiliza [el protocolo de validación externa](validacion-externa/README.md), guarda las fotos en `validacion-externa/fotos/` y completa `validacion-externa/registro.csv`. Estas imágenes permanecen separadas del entrenamiento.
